# 🐍 Python: Exercícios e Evolução

Repositório dedicado ao armazenamento da minha jornada de aprendizado em **Python**, reunindo scripts práticos, pequenos desafios de lógica e resolução de problemas básicos do dia a dia.

## 📁 Estrutura do Repositório

Aqui estão alguns dos scripts desenvolvidos nesta etapa inicial:

* **`area_triangulo.py`**: Cálculo da área de um triângulo a partir de dados fornecidos.
* **`aumento_salarial.py`**: Algoritmo para calcular percentuais e novos valores de salário.
* **`calculo_desconto.py`**: Script para aplicação de descontos em preços de produtos.
* **`celsius_para_fahrenheit.py`**: Conversão de escalas termométricas.
* **`consumo_combustivel.py`**: Cálculo de consumo médio de combustível por distância percorrida.
* **`dados_usuario.py`**: Coleta, formatação e exibição de dados de entrada do usuário.
* **`idade_em_meses.py`**: Conversão e cálculo de idade expressa em meses/dias.
* **`media_aluno.py`**: Processamento de notas e cálculo de média aritmética.
* **`soma_tres_numeros.py`**: Operações matemáticas básicas e manipulação de variáveis.
* **`terca_parte.py`**: Cálculo e exibição da terça parte de um número.

## 🚀 Tecnologias e Conceitos Utilizados

* **Linguagem:** Python 3.x
* **Conceitos:** Entrada e saída de dados (`input` / `print`), operadores aritméticos, estruturas condicionais e variáveis.
